# ChainTrust Metadata Standard

## Required fields

- Publication title
- Publication category
- Service type
- Authors
- Institution
- Engine
- Publication site
- GitHub repository
- GitHub path
- Report ID
- SHA-256 hash
- Generated timestamp
- Signer ID
- License
- Disclaimer

## Optional smart-contract fields

- Contract name
- Chain name
- Chain ID
- Contract address
- Source verification status
- Compiler version

## Category values

- `whitepapers`
- `audit-reports`
- `code-validation-reports`
- `technical-insights`
- `security-analysis`
